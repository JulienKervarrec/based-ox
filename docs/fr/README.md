# Parcours francais : based-ox (bibliotheque standard Ethereum de Base)

Lecture pedagogique du depot base/based-ox : le fork/mainteneur Base de ox, la bibliotheque standard TypeScript pour Ethereum, avec ses modules d account abstraction (ERC-4337, ERC-6492, ERC-7821, ERC-8010).

Sommaire :

Chapitre 1 Presentation de based-ox. Chapitre 2 Le module core, primitives sans etat et verbeuses par choix. Chapitre 3 Signatures enveloppees, ERC-6492 et ERC-8010. Chapitre 4 ERC-7821, executer des lots d appels. Chapitre 5 ERC-4337, les types UserOperation multi-versions. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
